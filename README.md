# Hermes Trading: demo site

A public walkthrough of Hermes, an autonomous trading research and execution system built by Sebastian Mabunda.

- `index.html`: the overview page, with short clips of each dashboard tab.
- `dashboard/`: a frozen, clickable copy of the real dashboard (snapshot of 3 November 2026). Account numbers, broker servers and prop-firm names are removed; figures are real.

The live system itself is private.
